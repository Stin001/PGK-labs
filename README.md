-------------------------Instrukcja obsługi-------------------------

1+LPM = dodanie kwadratu
2+LPM = dodanie wielokąta
3+LPM = dodanie koła
4+LPM = dodanie bitmapy

Obrót kształtu - naciśnij LPM na figurę i kliknij Q lub E

Zmiana rozmiaru kształtu - naciśnij LPM na figurę i kliknij Z lub X

Rozpoczęcie gry w Snake - SPACJA
